# ROSI Cash – Bedienung

1. **Getränk:** kurz antippen = +1; lange halten (ca. 600 ms) = −1.
2. **Pfand:** für konfigurierte Heißgetränke automatisch, auf dem Bon separat.
3. **Pfand zurück:** zurückgenommene Becher antippen; der Betrag wird abgezogen. Auch reine Rückzahlungen sind möglich.
4. **Bon:** Tablet rechts, Smartphone über „Bon anzeigen“; Gesamtsumme auf dem Smartphone dauerhaft sichtbar.
5. **Gegeben:** Münzen und Scheine antippen; langes Drücken subtrahiert eine Einheit. „Passend“ setzt den erhaltenen Betrag auf die Rechnungssumme.
6. **Rückgeld:** ROSI zeigt Rückgeld oder noch offenen Betrag. Bei negativer Rechnung zeigt es „Auszuzahlen“.
7. **Clear:** 1,2 Sekunden halten; danach kann die letzte Rechnung wiederhergestellt werden.
8. **Hilfe:** Fragezeichen antippen.

ROSI ist eine Rechenhilfe und kein Kassensystem. Zum Offlinebetrieb zuerst über HTTPS laden/installieren und danach im Flugmodus neu starten und testen.
