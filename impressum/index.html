GreenwayCash

Version 1.0 · Entwickelt von Stefan Rosenkranz

GreenwayCash ist eine kostenlose, offlinefähige Rechenhilfe für den Getränkeverkauf auf dem Weihnachtsmarkt. Sie berechnet Artikel, Becherpfand, erhaltenes Bargeld und Rückgeld.

Die Anwendung ist keine elektronische Registrierkasse, führt keine Transaktionshistorie und ersetzt keine gesetzlich erforderlichen Aufzeichnungen.

Quellcode und Lizenz: GreenwayCash auf GitHub (MIT-Lizenz)

Hinweise zum Datenschutz

Die Berechnung erfolgt auf deinem Gerät. Artikelmengen und erfasste Bargeldbeträge werden für die aktuelle Rechnung im lokalen Browserspeicher (localStorage) gespeichert. Zusätzlich kann ein geschlossener Installationshinweis lokal vermerkt werden. GreenwayCash verwendet keinen eigenen Login, keine eigene Transaktionsdatenbank und keine eingebundene Webanalyse.

Beim Abruf der Website können beim Hosting-Anbieter technische Verbindungsdaten einschließlich IP-Adressen in Server-Logs verarbeitet werden. Verantwortlichkeit, Speicherdauer und weitere Angaben zum Hosting müssen vor Veröffentlichung in einer vollständigen Datenschutzerklärung geklärt werden.
